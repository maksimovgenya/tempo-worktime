# План реализации: Веб-приложение для учёта рабочего времени (Time Tracker)

Компактная, надёжная и эстетичная система учёта рабочего времени сотрудников с живым таймером задач, фильтрацией периодов, подробными отчётами по каждому сотруднику, гарантированным сохранением данных после перезапуска и полной документацией решения.

---

### Подтверждённые решения и параметры

> [!IMPORTANT]
> На основе ответов в ходе интервью утверждены следующие проектные решения:
> 1. **Хранилище данных**: Гибридное сохранение — серверный JSON-файл (`data/timetracker.json` через Next.js Route Handlers) + синхронизация с `localStorage` браузера для мгновенного отклика и надёжности после перезапуска сервера.
> 2. **Периоды отчётов**: Быстрые пресеты («Сегодня», «Текущая неделя», «Текущий месяц») + произвольный выбор диапазона дат (календарь «С» — «По»).
> 3. **Демонстрационные данные**: Встроенный набор вымышленных сотрудников разных отделов и реалистичных завершённых задач за текущую неделю с возможностью сброса или очистки.
> 4. **Обязательные тестовые сценарии**: Повторный запуск таймера при уже активной задаче (мягкое переключение с фиксацией наработанного времени) и обработка пустого отчёта (понятный Empty State).
> 5. **Паспорт проекта**: Полное ведение `doc/passport.md` и составление `README.md` согласно критериям тестового задания на русском языке.

## 1. Концепция и возможности приложения

Приложение решает задачу прозрачного учёта трудозатрат команды без необходимости сложной авторизации или настройки внешних СУБД:

- **Управление сотрудниками**: добавление нового сотрудника (ФИО, должность, отдел), список активных участников команды с кратким статусом занятости.
- **Интерактивный таймер задач**:
  - Выбор сотрудника из выпадающего списка или быстрых кнопок.
  - Поле описания задачи с тегами категории (Разработка, Дизайн, Созвон, Аналитика, Тестирование).
  - Кнопки старта, паузы, возобновления и остановки с фиксацией в журнал.
  - Защита от конфликта запусков: если таймер уже тикает, система предлагает сохранить текущий отрезок и начать новую задачу либо отменить действие.
  - Ручное добавление пропущенного интервала времени.
- **Аналитика и отчёты**:
  - Сводные карточки по каждому сотруднику (суммарное рабочее время за выбранный период, количество задач, средняя длительность).
  - Фильтры периода: «Сегодня», «Эта неделя», «Этот месяц», «Произвольный интервал».
  - Фильтр по конкретному сотруднику или «Все сотрудники».
  - Обработка сценария «Пустой отчёт» с дружелюбным интерфейсом, объясняющим отсутствие записей за указанный период.
  - Таблица журнала задач с точным временем начала, завершения и длительностью в моноширинном формате (`02:45:10`).
  - Экспорт сводки в CSV для отчетности.
- **Надёжная персистентность**:
  - Серверный API (`/api/timetracker`) сохраняет данные в файл `data/timetracker.json`.
  - При перезапуске контейнера или вкладки браузера данные автоматически восстанавливаются.

## 2. Пользовательский интерфейс и дизайн-система

В соответствии с правилами дизайн-конституции SaaS & Dashboards (`references/3_saas_dashboard.md`):

- **Сетка и пропорции**:
  - Строгая 3-зонная шапка: Название бренда / Логотип `·` навигационные вкладки (`Таймер`, `Отчёты и аналитика`, `Сотрудники`, `О проекте / README`) `·` Кнопка сброса к демо-данным / индикатор синхронизации.
  - Рабочее пространство: карточка активного таймера с крупным контрастным цифровым табло (`tabular-nums font-mono`), быстрый выбор сотрудника, удобные кнопки управления.
  - Область отчётов: адаптивная сетка сводных показателей сотрудников + фильтры периодов в виде сегментированных кнопок + детальный журнал с моноширинными таймштампами.
- **Цветовая палитра (60-30-10)**:
  - 60% нейтральный чистый фон (`bg-slate-50 dark:bg-slate-950`).
  - 30% структурные поверхности карточек с тонкими границами `border-slate-200 dark:border-slate-800`.
  - 10% выразительные акценты: статусная индикация активности (`emerald` для запущенного таймера, `slate/indigo` для основных действий, `amber` для паузы).
- **Типографика**:
  - Заголовки и интерфейсные надписи: чёткий гротеск `Plus Jakarta Sans` / системные чистые шрифты.
  - Счётчики времени и числовые метрики: `font-mono tabular-nums`.

## 4. Этапы разработки и верификации

1. **Создание и фиксация `doc/passport.md`**:
   - Формирование технического паспорта приложения, описание архитектуры, сценариев, возможных проблем и способов их решения.
2. **Серверный слой хранения данных (`data/timetracker.json` и `/api/timetracker`)**:
   - Серверные хэндлеры чтения и записи с безопасной валидацией схемы данных.
   - Инициализация реалистичных вымышленных данных (5 сотрудников, 12 записей за разные дни).
3. **Клиентский модуль состояния (React State & Sync Hook)**:
   - Хук `useTimeTracker` с поддержкой мгновенного локального обновления (optimistic update) и фонового сохранения на сервер.
   - Тикающий таймер с миллисекундной точностью по `Date.now()` (не сбивается при сворачивании вкладки).
4. **Компоненты интерфейса**:
   - `TimerWidget`: панель запуска/паузы/остановки, выбор сотрудника, ввод задачи, диалог при повторном старте.
   - `EmployeeManager`: форма добавления сотрудника (валидация полей, аватар с инициалами, список команды).
   - `ReportDashboard`: переключение периодов («Сегодня», «Неделя», «Месяц», «Диапазон»), агрегация часов по каждому человеку, красивое состояние «Пустой отчёт», экспорт CSV.
   - `ProjectDocsModal / View`: интерактивный просмотр `README.md` прямо в интерфейсе для проверяющего.
5. **Создание документации `README.md`**:
   - Инструкция запуска, стек, использованные ИИ-инструменты и модели (Gemini), примеры промптов, описание найденных и устраненных ошибок, протоколы проверки сценариев (повторный пуск, пустой период).
6. **Обновление `doc/passport.md`**:
   - Полный отчёт обо всех реализованных компонентах, обработанных краевых случаях и методах их тестирования.
7. **Верификация сборки**:
   - Запуск `compile_applet` и проверка отсутствия ошибок TypeScript/React/Next.js.
